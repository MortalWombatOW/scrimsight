# Project Brief: Scrimsight v1

**Version:** 1.0 (Derived from PRD dated 2024-04-01)
**Status:** Initial Definition

## Core Goal

Scrimsight aims to be a powerful, browser-based analytical tool for Overwatch players, coaches, and teams using "ScrimTime" (DKEEH) workshop logs. It enables users to upload logs, process the data client-side, and gain insights through statistics and visualizations to improve performance and strategy.
