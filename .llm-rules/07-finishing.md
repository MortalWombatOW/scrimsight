# 07 - Finishing Touches

## Enhancements & Borders

- **Supercharge Defaults:** Enhance standard UI elements.
- **Accent Borders:** Use sparingly for visual interest.
- **Backgrounds:** Decorate backgrounds subtly.
- **Empty States:** Design empty states thoughtfully.
- **Fewer Borders:** Avoid overusing borders. Use shadows, background colors, or spacing.

## Experimentation

- **Think Outside the Box:** Challenge conventional UI patterns.
- **Analyze & Rebuild:** Analyze well-designed interfaces and rebuild them.
