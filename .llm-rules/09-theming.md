# 09 - Theming and Color Management

## DaisyUI Themes

- **Leverage:** Use DaisyUI's theming system.
- **Built-in Themes:** Utilize pre-designed themes (e.g., `base`).
- **CSS Variables:** Use DaisyUI's CSS variables (e.g., `--p`, `--s`, `--n`).
- **Responsive Theming:** Use media queries for automatic light/dark modes.

## Color Usage

- **Semantic Colors:** Follow consistent color usage: `primary`, `secondary`, `accent`, `neutral`, `base`, `info`, `success`, `warning`, `error`.
