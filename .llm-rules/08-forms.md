# 08 - Forms and Data Display

## DaisyUI Form Components

- **Use:** Use DaisyUI's form components: `input`, `textarea`, `select`, `checkbox`, `radio`, `toggle`, `range`, `file-input`, `form-control`, `label`.
- **Variants:** Use input variants for sizes and styles.
- **Validation:** Use validation states (e.g., `input-error`) and error messages.

## DaisyUI Data Display Components
- Use DaisyUI's data display components: `table`, `stat`, `card`, `collapse`, `badge`, `avatar`, `tooltip`.
